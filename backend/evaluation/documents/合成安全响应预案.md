# 合成安全响应预案

本文为公开合成测试资料，不是实际企业预案；事件分级、时限和角色均为演示数据。

## 事件分级

安全事件分为 P1 至 P4 四级。P1 表示核心数据被未授权导出或核心服务完全不可用，要求十分钟内响应、一小时内控制影响面；P2 表示单业务线数据泄露或关键服务降级，要求三十分钟内响应、四小时内控制影响面；P3 表示局部配置错误或非核心服务异常，要求两小时内响应、二十四小时内修复；P4 表示无实际影响的可疑扫描或误报，要求一个工作日内确认并归档。事件等级由值班负责人在初次研判时确定，后续可以升级但不得随意降级，降级必须由安全负责人书面确认。

多次同类 P4 事件在一个月内累计达到五次时，应合并升级为 P3 并做专项复盘。事件等级决定通知范围：P1 和 P2 必须通知安全负责人和业务负责人，P3 通知值班负责人，P4 只在事件台账登记。对外披露统一由公共关系团队负责，技术人员不得自行对外说明。

## 上报时限

发现安全事件后，发现人应在十五分钟内在事件平台登记，登记内容包括发现时间、影响系统、初步现象和已采取的措施。登记完成后系统自动创建事件编号，编号格式为 SEC 加六位年月加四位序号。值班负责人在收到登记后三十分钟内完成初次研判并确定事件等级，超时未研判会自动升级提醒。

P1 事件要求每小时更新一次进展，直到影响面得到控制；P2 事件要求每四小时更新一次；P3 事件要求每天更新一次；P4 事件在归档时补充结论即可。任何事件在控制影响面后二十四小时内提交初步报告，七十二小时内提交完整复盘报告。未按时提交报告的事件会在月度安全例会上通报。

上报内容只允许写入事件平台，不得在公共聊天群传播包含个人信息或密钥的截图。需要共享证据时，使用平台附件并设置访问期限，期限最长七天。

## 隔离流程

隔离操作包括下线受影响服务、吊销相关凭据、封禁异常来源地址和冻结受影响账号四类措施。吊销凭据前必须先确认凭据的使用方和影响范围，避免误伤正常业务；一次批量吊销超过二十个凭据时，需要安全负责人批准。封禁来源地址默认持续二十四小时，延长封禁需要填写工单并说明证据。

隔离期间不得删除日志、不得重建被感染主机、不得清空审计表，取证数据应原样保全至少三十天。恢复服务前需要完成影响面复核、凭据轮换和回归验证，三项都通过后才能解除隔离。解除隔离由值班负责人执行，并在事件平台记录解除时间和复核结论。

## 复盘要求

复盘报告必须包含时间线、根因、影响范围、处置过程和改进行动五项内容。时间线精确到分钟，根因需要区分直接原因和根本原因，影响范围需要列出受影响的系统、数据和时间窗口。改进行动必须指定负责人和完成日期，P1 和 P2 事件的改进行动需要在三十天内完成，逾期未完成会在下一次例会升级跟踪。

复盘结论只能用于改进流程，不得用于个人绩效评价。复盘材料保留两年，涉及个人信息的材料需要脱敏后归档。
